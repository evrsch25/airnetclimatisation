# 07_SEO.md

# Objectif SEO

Le référencement naturel est une priorité absolue.

Le site doit être conçu dès le départ pour obtenir un excellent positionnement sur Google.

Toutes les décisions de développement doivent prendre en compte le SEO.

Le SEO ne se limite pas aux balises Title et Description.

Il concerne également :

- l'architecture
- les performances
- l'accessibilité
- la qualité du contenu
- le maillage interne
- les données structurées
- l'expérience utilisateur

---

# Cible SEO

L'entreprise travaille principalement autour de :

Port-de-Bouc

Martigues

Istres

Fos-sur-Mer

Marignane

Vitrolles

Salon-de-Provence

Bouches-du-Rhône

Le site doit être optimisé pour le référencement local.

---

# Intentions de recherche

Les contenus doivent naturellement répondre aux recherches suivantes :

nettoyage climatisation

entretien climatisation

désinfection climatisation

nettoyage pompe à chaleur

nettoyage split

climatisation encrassée

entretien climatisation Port-de-Bouc

entretien climatisation Martigues

nettoyage climatisation Istres

nettoyage climatisation Fos-sur-Mer

etc.

Ne jamais faire du bourrage de mots-clés.

Les expressions doivent rester naturelles.

---

# Métadonnées

Chaque page possède :

Title unique

Meta Description unique

OpenGraph

Twitter Card

Canonical

Robots

Les titres doivent rester naturels.

Ne jamais dépasser les recommandations Google.

---

# Structure HTML

Toujours respecter :

1 seul H1

Puis :

H2

H3

H4

Jamais de saut de hiérarchie.

Les titres doivent être descriptifs.

---

# URLs

Créer des URLs courtes.

Exemples :

/

prestations

contact

pourquoi-nous

zone-intervention

mentions-legales

cgu

Prévoir plus tard :

/martigues

/istres

/fos-sur-mer

/marignane

etc.

---

# Maillage interne

Chaque page doit contenir des liens vers :

Prestations

Contact

Zone d'intervention

Pourquoi nous

Mentions légales

Créer un maillage cohérent.

Ne jamais laisser une page isolée.

---

# Images

Toutes les images doivent posséder :

alt

title si pertinent

nom de fichier optimisé

Exemple :

nettoyage-climatisation-martigues.webp

Jamais :

IMG_4588.jpg

---

# Formats

Utiliser :

WebP

AVIF lorsque pertinent.

Compression maximale sans perte visible.

---

# Données structurées

Mettre en place :

LocalBusiness

Organization

FAQPage

BreadcrumbList

WebSite

ContactPage

Service

Utiliser JSON-LD.

Ne jamais utiliser Microdata.

---

# Sitemap

Créer automatiquement :

sitemap.xml

Inclure toutes les pages.

Prévoir les futures pages villes.

---

# Robots

Créer :

robots.txt

Autoriser l'indexation.

Bloquer uniquement les pages techniques.

---

# Open Graph

Toutes les pages possèdent :

image

title

description

url

siteName

locale

type

---

# Réseaux sociaux

Prévoir les métadonnées même si les comptes ne sont pas encore actifs.

---

# Performances SEO

Objectifs :

LCP < 2,5 s

CLS < 0,1

INP excellent

Éviter :

JavaScript inutile

CSS inutile

Images trop lourdes

Fonts inutiles

Hydratation excessive

---

# SEO local

Créer un contenu mettant naturellement en avant :

Port-de-Bouc

Martigues

Vitrolles

Marignane

Fos-sur-Mer

Salon-de-Provence

Bouches-du-Rhône

Toujours de façon naturelle.

# Contact

Prévoir les données structurées.

# Accessibilité et SEO

Une bonne accessibilité améliore également le référencement.

Toujours :

alt

ARIA

labels

navigation clavier

contrastes

---

# Objectif final

Le site doit être capable de devenir la référence locale sur les recherches liées au nettoyage de climatisation dans les Bouches-du-Rhône.

Le SEO doit être intégré au développement dès le premier jour et non ajouté après la mise en ligne.
