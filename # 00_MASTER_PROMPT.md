# Objectif du projet

Créer le site internet officiel de l'entreprise

AIR NET CLIMATISATION

Le site est un site vitrine.

Son objectif n'est PAS de vendre en ligne.

Son objectif est :

- inspirer confiance
- présenter clairement les prestations
- obtenir des demandes de devis
- générer des appels téléphoniques
- rassurer les visiteurs
- montrer le professionnalisme de l'entreprise
- être extrêmement bien référencé localement

Le site doit donner immédiatement l'impression d'une entreprise :

- sérieuse
- propre
- rigoureuse
- moderne
- professionnelle
- honnête

Le visiteur doit penser :

"Cette entreprise travaille proprement."

# Ce qu'il ne faut PAS faire

Ne jamais utiliser :

❌ glassmorphism

❌ gros dégradés flashy

❌ fond violet

❌ néons

❌ effets Apple exagérés

❌ Hero gigantesque

❌ animations inutiles

❌ cartes qui flottent partout

❌ ombres énormes

❌ coins totalement arrondis (9999px)

❌ boutons énormes

❌ couleurs agressives

❌ sections de plusieurs écrans de hauteur

❌ effets qui distraient l'utilisateur

Le design doit inspirer confiance.

Jamais impressionner gratuitement.

---

# Ce qu'il faut faire

Créer un site :

élégant

haut de gamme

sobre

professionnel

fluide

léger

lumineux

aéré

Chaque élément doit avoir une utilité.

Les animations doivent uniquement améliorer l'expérience.

Jamais attirer l'attention inutilement.

# Identité visuelle

Le logo fourni est la référence.

Les couleurs principales doivent être construites autour du logo.

La dominante doit être :

- blanc
- bleu
- gris très clair

Le bleu servira principalement :

- CTA
- liens
- éléments importants
- icônes
- titres

Le blanc doit rester très dominant.

Le site doit respirer.

# Qualité attendue

Tu ne développes pas un projet étudiant.

Tu développes un site destiné à une véritable entreprise.

Chaque décision doit être prise comme si le site allait rester en production pendant plusieurs années.

La priorité est toujours :

qualité > rapidité

maintenabilité > quantité de code

lisibilité > complexité

UX > effets visuels

SEO > animations

Toujours terminer une tâche par une vérification de la qualité du résultat avant de passer à la suivante.
